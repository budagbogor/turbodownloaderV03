# 🚀 Cara Memasang TurboDownloader Browser Extension (IDM-Class Video Sniffer)

Modul Ekstensi Browser ini berfungsi secara otomatis mendeteksi video di **semua situs** (YouTube, TikTok, Facebook, Instagram, Anime, Movie Portals, dll) dan menampilkan tombol melayang **"Download Video"** seperti halnya **IDM Integration Module**.

---

## 📌 Cara Install di Google Chrome / Microsoft Edge / Brave / Opera

1. **Buka Halaman Ekstensi Browser**:
   * Untuk **Google Chrome**: Ketik `chrome://extensions` di address bar dan tekan `Enter`.
   * Untuk **Microsoft Edge**: Ketik `edge://extensions` di address bar dan tekan `Enter`.

2. **Aktifkan Mode Pengembang (Developer Mode)**:
   * Sakelar/toggle **Developer Mode** berada di **Pojok Kanan Atas** halaman ekstensi. Geser menjadi **ON**.

3. **Muat Ekstensi (Load Unpacked)**:
   * Klik tombol **"Load unpacked"** (atau **"Muat yang tidak dipaketkan"**) di pojok kiri atas.
   * Pilih folder lokasi proyek ini:
     `c:\Users\snwd\Videos\turbodownoader\TurboDownloader-1\extension`

4. **Selesai! 🎉**:
   * Modul **TurboDownloader Integration Module** sekarang sudah aktif di browser Anda.

---

## 🎯 Cara Penggunaannya

1. Buka situs video apapun (contoh: YouTube, TikTok, Facebook, Anime portal).
2. Putar video tersebut.
3. Di **Pojok Kanan Atas Pemutar Video**, akan muncul tombol melayang melayang:
   **`⚡ Download Video [Turbo]`**
4. Klik tombol tersebut, dan video akan **langsung otomatis dikirim ke aplikasi TurboDownloader** untuk diunduh dengan kecepatan tinggi!
